# Resume/CV Folder

Place your CV/Resume PDF file here.

## Expected File

- `CV.pdf` - Your CV/Resume file

## Instructions

1. Add your CV/Resume PDF file to this folder named `CV.pdf`
2. The file will be accessible at `/resume/CV.pdf`
3. Download button will save it as `Slav_Lambov_CV.pdf`

## Format

- File type: PDF
- File name: `CV.pdf` (exactly as shown)
- Size: Recommended under 1MB for quick downloads
- Make sure the file is up to date before deployment
