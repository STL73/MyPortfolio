# Certificates Folder

Place your certificate PDF files here.

## Expected Files

- `react-certificate.pdf` - React Developer Certificate
- `javascript-certificate.pdf` - JavaScript Advanced Certificate
- `webdesign-certificate.pdf` - Web Design Fundamentals Certificate

## Instructions

1. Add your certificate PDF files to this folder
2. Update the file names in `src/constants/index.js` (certificatesData array) if different
3. Files will be accessible at `/certificates/[filename].pdf`

## Format

- File type: PDF
- Naming: Use lowercase with hyphens (e.g., `my-certificate.pdf`)
- Size: Keep files under 500KB for optimal performance
